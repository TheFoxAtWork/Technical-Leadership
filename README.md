# Technical Leadership

Public resources for technical leadership leveraging open source values.

## Articles

Explorations of technical leadership practices and patterns:

- **[Patience & Active Listening](patience-listening/)** - Tolerance, calm, and validation techniques for effective technical communication and conflict resolution
- **[Technical Mediation](technical-mediation/)** - Structured approaches to resolving technical disagreements and providing actionable feedback

## Skills

Claude Code skills applying technical leadership principles as executable patterns:

- **[Voice Transform](skills/voice-transform/)** - Transform AI-generated content into clear, direct, professional writing using proven structural and tonal patterns

Clear communication is a core technical leadership skill. The voice-transform skill packages proven writing patterns (directness, concrete examples, transparent reasoning) as an immediately usable Claude Code skill.

## Using This Repository

**Articles**: Read directly on GitHub or clone locally for offline reference  
**Skills**: Clone the repo and symlink to `~/.claude/skills/` to use with Claude Code

```bash
# Clone repository
git clone git@github.com:TheFoxAtWork/Technical-Leadership.git

# Install voice-transform skill (example)
ln -s ~/Documents/GitHub/Technical-Leadership/skills/voice-transform ~/.claude/skills/voice-transform
```
